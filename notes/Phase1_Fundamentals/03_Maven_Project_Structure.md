# Maven & Spring Boot Project Structure

Every professional Spring Boot project generated by Maven follows the exact same folder structure. This makes it easy for any Java developer in the world to open your project and instantly know where things are.

## The `src/` Directory
`src` stands for Source. This contains all the code you write.

### 1. `src/main/java/`
This is where your actual Java application lives. Everything inside this folder is compiled and run when you start the server.
* **`com/devopshub/backend/`**: This is your "Base Package" (Reverse Domain Name). All of your code goes inside here.
  * **`controller/`**: Handles internet traffic (The Waiters).
  * **`service/`**: Contains business logic (The Chefs).
  * **`repository/`**: Talks to the database (The Fridge).
  * **`entity/`**: Database table blueprints (The Ingredients).
  * **`dto/`**: JSON shapes sent to the internet (The Plates).
  * **`BackendApplication.java`**: The main starting point of the entire application (It contains `public static void main`).

### 2. `src/main/resources/`
This folder is for everything that your application needs to run, but is **not** Java code.
* **`application.yaml` / `application.properties`**: The master configuration file (database passwords, server ports, etc).
* **`static/`**: If you were serving a basic HTML/CSS/JS website directly from Spring Boot (without React/Angular), you would put the CSS and JS files here.
* **`templates/`**: Used for server-side HTML rendering (like Thymeleaf). *Since we are building a REST API, we will likely leave `static` and `templates` empty!*

### 3. `src/test/java/`
This is completely isolated from your main code. 
* This is where you write automated tests (using JUnit and Mockito). 
* When you deploy your application to production, Maven automatically strips this folder out so your production server stays lightweight. We will dive heavily into this in Phase 7!
